# Project Overview

Project Name: StarGazer's Atlas

Description: A web application that *simulates* a personalized planetarium experience. Users "subscribe" to receive a monthly curated set of constellations tailored to their location and simulated stargazing conditions. The app acts as a companion to a (mocked) physical subscription box, enhancing the learning experience.

Features:
*   Mock Subscription: A simulated subscription flow with user profile and preference settings (location, light pollution level, telescope type, etc.).
*   Monthly Constellation Unveiling: Each month, users unlock a new set of constellations within the app.
*   Interactive Star Maps: Detailed, zoomable star maps with constellation overlays and information.
*   3D Constellation Viewer: A simulated 3D model of each constellation, allowing users to explore its structure in space.
*   "Backyard Observatory" Builder: A gamified feature where users can virtually build their own observatory by "collecting" equipment (telescopes, filters, cameras).
*   Learning Resources: Articles, videos, and quizzes about each constellation (mythology, scientific data, etc.).

Technology Stack:
*   Cloudflare next-on-pages framework (NextJS) for the web application.
